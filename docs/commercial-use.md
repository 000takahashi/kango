勘合は Apache License 2.0 で公開しています。**会社のアプリやサービスに組み込んで、有料で提供して構いません。** 使う前の連絡や許可も、使用料も要りません。

このページは、使う時に気をつけることを、わかりやすくまとめたものです。**正式な条件は [LICENSE](../LICENSE) の本文です。** この説明は法的な助言ではありません。具体的な使い方が条件に合うかは、弁護士などの専門家に確かめてください。

## できること

- 勘合を、そのまま、または手を加えて、アプリ・サービス・製品に組み込む（有料でも無料でも）。
- 手を加えたものを配る・売る。手を加えた部分には、自分で決めた条件（ライセンス）を付けられます。
- 自分の名前と責任で、利用者に保証やサポートを（有料でも）提供する（第9条）。

## 配る時に守ること（第4条）

アプリに組み込んで配る、部品として配るなど、勘合（手を加えたものを含む）を**人に渡す**時は、次のことを守ります。

1. **ライセンスの写し（[LICENSE](../LICENSE)）を一緒に渡す。**
2. **[NOTICE](../NOTICE) の中身を、受け取った人が読める所に載せる。** アプリなら「ライセンス」や「著作権の表示」の画面など、ほかの部品の表示を載せている所で構いません。
3. **手を加えたファイルには、手を加えたことを書く。**
4. **元のファイルにある著作権などの表示を消さない。**

サーバーの中だけで動かし、勘合そのものを人に渡さない使い方（判定の結果だけを返すサービスなど）は、ふつう「配る」には当たらないと考えられています。その場合も、どこかに「勘合（kango）を使っています」と書いてもらえるとうれしいです。

## 名前について（第6条）

- Apache License 2.0 は、名前やロゴを使う権利までは与えていません。**「勘合」「kango」を、提供元が作った・認めたと誤解される形で、製品の名前などに使わないでください。**
- 「勘合（kango）を使っています」のように、**使っていることを説明するのは歓迎です。**
- **「勘合で安全と判定済み」のように、勘合が安全を保証したかのような表示はしないでください。** 勘合が言えるのは「割符が合ったか」までです。
- 会社の一覧（[data/brands.csv](../data/brands.csv)）にある会社名は、それぞれの会社のものです。勘合は、会社を見分けるためだけに使っています。製品の中で、それらの会社と提携している・認められていると誤解される表示をしないでください。

## 保証がないこと（第7条・第8条）

勘合は「現状のまま」提供しています。答えが正しいことや、被害を防げることを保証するものではありません。提供元は、勘合を使ったことで起きた損害の責任を負いません。

勘合の答えは、判断の手がかりです。製品の中でも [結果の見せ方](integration.md#結果の見せ方) の作法（青を「安全」と言い換えない・青以外では相談先を出す・結果を見て勝手に動かない）を守ってください。

## お願い（条件ではありません）

- 勘合を使った製品を作ったら、Issue などで教えてもらえるとうれしいです。
- 会社の公式の住所を確かめたり、新しい手口の見本を見つけたりしたら、ぜひ戻してください（[会社と規則の足し方](extending.md)）。
- 偽物の連絡が青になる抜け道を見つけたら、公開せずに知らせてください（[SECURITY.md](../SECURITY.md)）。
- 版を上げる時は、[変更の記録](../CHANGELOG.md) で答えの変わり方を確かめてください。
